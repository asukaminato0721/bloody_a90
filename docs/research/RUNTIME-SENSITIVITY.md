# 即时 DPI 和回报率

2026-10-20，A90 型号 `04fd`、固件 `07`、核心 `2` 的实机检查通过。
驱动现在保存灵敏度后立即应用 DPI 和回报率，不需要拔插。
本记录区分运行状态更新和闪存保存。

## 官方程序和固件证据

官方 EXE 的 `005a1dc8` 调用 `0059eddc`，发送命令 `0d` 和八字节数据。
`0043c5d8` 先应用运行状态，再检查灵敏度块的校验和并决定是否保存。
汇编 `0043c66c` 至 `0043c6fe` 确认以下字节顺序。
偏移从报告的第 8 字节开始计算。

| 数据偏移 | RAM 字节地址 | 内容 |
| --- | --- | --- |
| 0 | `0026` | 档位数减一 |
| 1 | `0027` | 当前档位，零为第一档 |
| 2 | `0028` | X 比例低字节 |
| 3 | `0029` | Y 比例低字节 |
| 4 | `002a` | 传感器编码 |
| 5 | `0023` | 回报率编码，1、2、4、8 分别对应 1000、500、250、125 Hz |
| 6 | `002d` | X 比例高字节 |
| 7 | `002e` | Y 比例高字节 |

报告头为 `07 0d 00 00 00 00 00 00`。报告补零到 64 字节。
固件命令表项 `11a0` 跳到 `12e1`。该函数复制上述字段，不写闪存。
传感器主循环 `1981` 至 `1983` 比较 RAM `002a` 和 RAM `0162`。
编码改变时调用 `19bd`，更新 RAM `0162`，并经 `1a3e` 写入传感器寄存器 `1b`。
物理 DPI 切换路径 `0a94` 也更新 RAM `002a`。
传感器初始化函数 `19ee` 使用相同的寄存器和编码。
以上固件地址都是字地址。

驱动等待运行字段与请求一致，并检查 RAM `0162` 和 RAM `0157` 的就绪位。
这个检查确认固件处理了传感器编码。它不测量实际 CPI。

## 驱动保存流程

- DPI 保存：检查全部参数，保存灵敏度块，应用运行 DPI、回报率和抬起高度。
- 回报率保存：保存本页字段，重新读取当前运行 DPI，只修改运行回报率。
- 抬起高度保存：保存本页字段，只应用抬起高度，保留当前运行 DPI 和回报率。
- 备份恢复：恢复可写页后，应用备份中的灵敏度设置。

原始闪存备份不含瞬时运行参数。
因此恢复备份会应用其中保存的档位和回报率，不会重建备份时的临时硬件切换状态。
若闪存保存成功而即时应用失败，错误信息会明确说明保存已经完成。

本机启用了硬件回报率设置。固件重新启动时可能从一般设置区选择回报率，
覆盖灵敏度块中的回报率。即时应用不修改这项硬件设置。
界面保留重新插入后可能覆盖回报率的提示。

## 实机结果

每阶段采集三秒移动事件，不独占输入设备。
下表为完整保存流程测试的结果。
事件间隔使用含 X/Y 位移的 evdev `SYN_REPORT` 时间戳计算中位数。

| 阶段 | 八字节数据或设置 | 移动帧 | 间隔中位数 |
| --- | --- | ---: | ---: |
| 原运行状态 | `02 01 40 40 23 08 00 00` | 375 | 8000 µs |
| 改为 800 DPI | `02 01 40 40 11 08 00 00` | 372 | 8000 µs |
| 改为 500 Hz | `02 01 40 40 11 02 00 00` | 1173 | 2000 µs |
| 恢复原运行状态 | `02 01 40 40 23 08 00 00` | 375 | 8000 µs |
| 通过保存接口应用 DPI | 两档 800/1600，选第二档，500 Hz | 1498 | 2000 µs |
| 通过保存接口应用回报率 | 当前切到第一档，保存 1000 Hz | 2570 | 1000 µs |

回报率保存前的运行档位与闪存保存档位不同。
测试确认保存回报率没有覆盖当前运行档位。
同一测试还确认抬起高度保存没有改变运行 DPI 或回报率。
测试最终恢复原灵敏度页、运行状态和抬起高度。
全部 32768 字节闪存与测试前逐字节相同。

早期失去移动的测试还发送过命令 `03`，没有隔离失败原因。
本次单独检查 `0d`，各阶段均有连续移动事件。
命令 `03`、`1e` 和 `2a` 继续禁止发送。

## 复现

关闭其他会访问鼠标的进程。测试期间持续移动鼠标。
测试会临时写入灵敏度页，再恢复测试前的完整页和运行状态。

```sh
A90_TEST_RUNTIME_DPI=1 cargo test --locked --lib runtime_sensitivity_hardware -- --ignored --nocapture
cargo run -- --runtime-sensitivity
```

命令行查询只读取运行值。完整测试需要 hidraw 和对应输入设备的读取权限。
测试使用恢复保护对象，在常规错误或断言失败时尝试恢复。
进程被强制终止或设备断开时，保护对象无法完成恢复。
