# 4-Way Wheel / Evolutionary Wheel

2026-10-21，区域滚动接入当前 KDE Wayland。
入口为“灵敏度 → 滚轮 → 4-Way Wheel · 区域滚动”。
默认左侧 90% 保留纵向滚动，右侧 10% 转为横向滚动。
分界可在 10% 至 90% 之间设置，也可交换两侧用途。
核心 1 至 4 分别保存区域滚动开关。
连接或重启输入服务前，程序重新读取鼠标核心，再选择对应开关。
未知核心不会启用区域滚动。
“每应用分界”可分别保存应用的分界位置。
匹配 KWin 的 `desktopFileName`，缺少此值时匹配 `resourceClass`。
规则忽略标识两端空白及 ASCII 大小写。未匹配的应用使用默认分界。
规则最多为 128 条。应用标识最多为 512 字节。
区域属于指针所在窗口，不依赖前台窗口。
桌面、面板及不属于普通窗口的区域保留原来的滚动。

## KDE 实现

持久 KWin 脚本每 100 ms 读取指针所在普通窗口的 `frameGeometry`。
它通过独立 D-Bus 回调更新有界缓存。
回调只接受启动时确认的 KWin 总线拥有者。
输入线程只读取缓存，不等待 D-Bus 调用。
区域坐标使用 KWin 逻辑坐标，支持负坐标及小数坐标。
Linux 按应用标识选择分界，不按 Windows 的三层窗口类别选择。
不会自动导入 Windows 窗口类别记录。

横向区域把 `REL_WHEEL` 转为反向的 `REL_HWHEEL`。
高分辨率事件 11 同时转为反向的事件 12。
一次 evdev 帧使用同一方向，避免两个表示进入不同轴。
滚轮向上对应向左，滚轮向下对应向右。
桌面的自然滚动选项继续处理虚拟鼠标的输入。
普通移动、按键及已有横向滚动保持转发。
源设备只提供普通滚轮时，镜像不会声明它不提供的高分辨率纵向轴。

区域滚动、普通手势及厂商通知触发的手势共用一个物理输入读取器。
只启用区域滚动时也可启动读取器。
停止全局手势后，已启用的区域滚动继续运行。
同时按下右键和中键会停止整个输入接管。
明确重新应用后才恢复接管。
关闭程序会停止接管并卸载区域脚本。

横向区域可显示方向图标。纵向区域及无普通窗口的区域隐藏图标。
图标由独立 KWin QML 脚本创建，位置使用全局逻辑坐标。
图标跟随指针，并限制在指针所在输出范围内。
图标不接受指针或键盘输入，也不获取焦点。
设置页可关闭方向图标。
启用前先检查图标脚本能否启动，再接管输入。
图标需要 Qt Quick、KWin QML 和 Plasma D-Bus QML 模块。
关闭图标后，区域滚动不需要加载这些 QML 模块。

缓存超过 600 ms 未更新时，服务报错并释放输入。
回调端点消失后，KWin 定时器会在十次未获应答的周期后卸载自身。
设置保存在 `~/.config/bloody-a90/wheel.xml`。
保存拒绝外部改动、未读入的已有文件和符号链接。
已保存的启用状态随程序连接鼠标时恢复。
文件版本 2 保存四个核心开关及方向图标开关。
版本 1 的全局启用状态迁移为四个相同的核心开关，保留其原有效果。
“重新读取”只读取文件，实际应用仍需点击“应用区域滚动”。

KWin 接口依据为 [KDE 脚本 API](https://develop.kde.org/docs/plasma/kwin/api/)
及 [KWin 脚本实现](https://invent.kde.org/plasma/kwin/-/blob/master/src/scripting/scripting.cpp)。
图标使用 [KWin 内部窗口](https://invent.kde.org/plasma/kwin/-/blob/master/src/internalwindow.cpp)
及 [Plasma D-Bus QML 接口](https://invent.kde.org/plasma/plasma-workspace/-/blob/master/components/dbus/dbusconnection.cpp)。
本机接口兼容性以独立 KWin 测试结果为准。

## 检查

常规检查覆盖区域边界、负坐标、反向区域、同帧两种滚轮事件、设置往返和文件冲突。
应用规则检查覆盖独立分界、默认分界、重复标识及含 XML 特殊字符的标识。
共用设置检查覆盖普通手势、原生按键手势和只启用滚轮的情况。
设置页检查确认读取已保存设置不会错误宣称服务正在运行。
核心开关检查覆盖独立选择、未知核心和版本 1 文件迁移。

独立 KWin 检查通过：

- 原生 Wayland 和 XWayland 窗口均可识别左右区域。
- 非前台窗口使用其自身的区域。
- 两类窗口均按其应用标识选择独立分界，未匹配规则使用默认分界。
- 抓取的虚拟输入路径输出恰好一组横向普通事件和高分辨率事件。
- 同一读取器仍可识别手势并输出 Ctrl+X，所有生成键均释放。
- 紧急停止后，源设备可重新接管，两个虚拟输出设备均移除。
- 正常停止卸载脚本并删除临时目录。
- 回调端点消失后，旧缓存失效，脚本自动卸载。
- 方向图标在横向区域显示，在纵向区域隐藏。再次进入横向区域后重新显示。
- 图标不获取焦点，KWin 的指针命中检查会跳过图标。
- 停止后方向图标移除。回调端点消失后，方向图标脚本自行卸载。
- 关闭方向图标时，不创建图标脚本。

本机 A90 的只启用区域滚动、启停及输入释放检查通过。
按读取到的当前核心选择设置，以及启用方向图标后的启停检查也通过。
检查前后的按键表头、运行配置和通知模式一致。
这项检查没有写闪存，没有验证人工滚动在实际应用中的视觉效果。

## 剩余功能

已实现区域转换、每应用分界、每核心开关、方向图标及统一输入生命周期。
整页滚动、横向字符数和可拖动分隔图标尚未实现。
Windows 窗口类别规则未自动转换为 Linux 应用规则。
这些项目仍属于功能检查的未完成项。
