# A90 抬起高度与按键响应

分析对象与 [PROTOCOL.md](PROTOCOL.md) 相同。以下地址均来自官方 EXE 或 A90 固件 07。
本文件补充 [WRITES.md](WRITES.md) 中的保存流程。

## 页面草稿和保存

灵敏度页共用一个保存块。回报率和抬起高度的应用操作以最新设备快照为底，
只改变对应字段。保存后的界面刷新也只更新对应字段。
DPI 的“取消”不再重载按键和抬起高度草稿。
测试按全部六种顺序保存 DPI、回报率和抬起高度，并检查未保存的按键草稿。

## 抬起高度

EXE `0044bff0` 针对传感器 `0cff` 使用 `15 - index`。
界面索引从 0 开始。工具显示 1 至 16 级，因此编码为 `16 - level`。
等级不是毫米数值。

EXE `00450368` 至 `004503a0` 将编码与启用位 `40` 合并，写入灵敏度表第 `1f` 字。
固件 `0acd` 至 `0ad1` 将低字节载入 bank 0 RAM `24`。
固件 `1a97` 检查启用位，并将低五位乘以 8 后与传感器读数比较。
读数低于阈值时，固件清除本次位移。
工具修改已知字段，并保留模板中的其他位。

EXE `005a28c8` 用命令 `13` 写入运行值。
请求字节 4 的 `80` 表示写入，字节 8 包含编码。
EXE 设置编码中的 `80` 位，表示显式选择了等级。
固件 `1202` 至 `120c` 只修改 RAM `24`。
此命令不访问传感器寄存器。
读模式的响应字节 8 是当前编码，字节 9 是校准最小值。

## 表面校准

EXE `005a27cc` 发送命令 `12`，数据字节为 `80`，开始采样。
EXE `005a284c` 发送数据字节 `00`，停止采样。
固件 `11ff` 至 `1201` 将该字节写入 bank 1 RAM `11`。
固件 `1a7f` 至 `1a96` 在校准期间记录传感器读数除以 8 后的最小值。
最小值在 bank 1 RAM `0f`。其 `80` 位表示收到了样本。

EXE `0044bc60` 先读取命令 `13` 的三字节状态，再结束采样。
它检查最小值的 `80` 位，并调用 `0044bf04`。
对于 A90，转换结果为零起点索引 `15 - min(code, 15)`。
工具显示的等级为 `16 - min(code, 15)`。
没有样本时，工具返回错误。

工具使用五秒采样窗口。用户必须让鼠标接触使用表面并持续移动。
校准只载入等级草稿。用户点击“应用”后，工具保存并应用该等级。
采样结束或发生错误时，工具恢复进入采样前的状态字节。
关闭窗口时，主线程等待设备线程完成清理。

## 硬件按键响应时间

EXE `0073b558` 从界面读取 0 至 16 ms，将值加一后写入全局 `016137c0`。
`0043b1e8` 将该值传给配置构建器。
`00619b60` 在 `0061a65a` 复制该字段。
最终字段为按键主向量第 6 字。
固件 `0ad3` 至 `0ad7` 读取此字段，并写入 bank 0 RAM `25`。
工具保留该字的高字节。

单独保存主向量不会立即更新 RAM `25`。
EXE `005a1d54` 用命令 `0c` 更新运行状态。
固件 `1322` 至 `132c` 接收以下三个数据字节：

| 请求字节 | 目标 |
| --- | --- |
| 8 | bank 2 RAM `64`，最大配置序号。 |
| 9 | bank 2 RAM `62`，配置选择寄存器。 |
| 10 | bank 0 RAM `25`，按键响应时间加一。 |

工具先读取前两个字节，然后将原值与新响应时间一起发送。
工具检查 RAM `25` 的读回值。
此过程保留运行中的配置和配置数量。

硬件响应时间与桌面双击速度是两个独立设置。
EXE `0073b684` 修改 Windows 双击设置。它不修改鼠标的响应时间。

## 验证范围

单元测试检查抬起高度的编码、校准样本标志、响应时间范围及模板保留。
配置集成测试检查射击槽位和响应时间经过闪存编码与解析后保持一致。
硬件读回可检查保存值与运行值。它不能证明实际抬起距离或物理按键的延迟。

2026-10-20 的实机检查结果：

- 保存 8 ms 后，RAM `25` 读回 `09`。恢复后读回 `01`。
- 保存抬起高度 16 级后，RAM `24` 读回 `c0`。恢复后启用位清零。
- 一秒校准返回 1 级。结束后 RAM `111` 读回 `00`。
- 全部设置恢复后，32768 字节闪存与测试前完全相同。
  SHA-256 为 `f32caca4fd72a81c8ca3fb823ec1fab26f84f53533659de842abb35945bf2676`。

上述检查没有测量物理距离或延迟，也没有保存校准所得的 1 级设置。
