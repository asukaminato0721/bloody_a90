# KDE Wayland 桌面鼠标设置

官方程序中的指针速度、双击间隔和滚动行数属于桌面设置。
这些值不写入鼠标闪存。
实现位于 `src/host.rs`。

## 设备选择

程序从 KWin 的 `ListPointers` 获取设备，再检查 A90 的厂商和产品编号。
还必须检查 `supportsPointerAcceleration=true`。
本机 KWin 同时列出鼠标接口和名为 `COMPANY  USB Device  Keyboard` 的键盘接口。
键盘接口不支持指针加速，其速度读取恒为零。
此前选取列表中的第一个 A90 接口，会返回错误的零值。
当前实现已排除该接口。

启用全局手势时，虚拟鼠标复制物理身份和名称。
程序会更新所有支持指针加速的匹配接口。
保存时保留 libinput 名称末尾的空格，避免写入错误的配置组。

## 保存位置和效果

- 指针加速写入 KWin 设备属性，立即生效。
- 同一值保存到 `kcminputrc` 中对应的 Libinput 设备组。
- 双击间隔和滚动行数保存到 `kdeglobals` 的 KDE 组。
- 后两项由新启动的程序读取，现有程序可能保留原值。

## 实机检查

2026-10-21，检查通过以下流程：

1. 读取每个适用接口的速度，并记录三个配置键的原值或不存在状态。
2. 临时写入不同的速度、双击间隔和滚动行数。
3. 检查驱动读回值和配置键值。
4. 启动独立 Qt6 程序，通过 `QStyleHints` 读取双击间隔和滚动行数。
5. 恢复原运行值和原配置键。原来不存在的键会删除。
6. 再次读取，确认运行值和配置键均与测试前一致。

测试在错误退出时也执行恢复。
如果某个目标在测试期间被其他程序修改，恢复不会覆盖该外部修改。
测试不生成输入，也不写鼠标闪存。
它没有测量人工双击速度或用户实际感受到的滚动距离。

```sh
env A90_TEST_KDE_HOST=1 cargo test --locked --lib host::tests::kde_settings_write_read_and_restore -- --ignored --nocapture
```

此检查会临时修改当前桌面设置，需要访问工作区外的 KDE 配置文件。
独立读取程序位于 `tests/fixtures/desktop_settings.cpp`，测试在结束时删除编译产物。
