# AMC 宏库

奥斯卡III 页面提供本地宏库和宏编辑器。
默认目录为 `$XDG_DATA_HOME/bloody-a90/macros`。
未设置该变量时，使用 `~/.local/share/bloody-a90/macros`。
宏库目录可以在页面中修改。该选择保存在应用状态中。

## 官方入口

undelphi 从 `TtabMacroEdit3` 恢复了这些事件名称和地址：

| 操作 | 地址 |
| --- | --- |
| 新建分类 | `0070fb44` |
| 新建宏 | `0070fe68` |
| 保存 | `007116e4` |
| 另存为 | `007125b4` |
| 删除分类 | `00713d4c` |
| 分类重命名 | `00714a44` |
| 删除宏 | `00714e80` |
| 宏重命名 | `0071562c` |

本实现使用目录和 AMC 文件提供这些操作。
它不读取官方软件的 Windows 用户配置数据库。
可把宏库指向含有分类子目录的 AMC 目录，例如官方的 `DefaultLog/kernel3`。
外部 AMC 文件也可通过下方编辑器导入，再另存为库中的新宏。

## 文件行为

- 分类是一级子目录。每个分类下的 `.amc` 文件按名称排序。
- 加载文件不会写鼠标。宏通过现有编译器和按键保存流程进入鼠标。
- 新建和另存为拒绝覆盖同名文件。
- 保存先检查磁盘内容是否仍与载入时相同。外部修改会使保存失败。
- 保存先写完整临时文件，再提交名称，避免中途显示部分内容。
- 重命名拒绝替换已有名称，包括符号链接。
- 删除将文件或整个分类移入本库的 `.trash` 目录。
- “恢复上次删除”在本次会话中恢复最近一项。原名称被占用时拒绝恢复。
- 重命名保留未保存的编辑内容。文件读取期间输入的新内容也继续保留。

分类和文件名不能包含路径分隔符、控制字符，也不能以点开头。
库内分类和宏文件必须是实际目录或文件，不能使用符号链接。
这些限制使文件操作保持在选定的宏库内。

## 检查

测试覆盖分类和文件的完整操作、保存冲突、名称冲突、删除恢复、
路径和符号链接拒绝，以及编辑器草稿保留。
真实宏库检查为只读操作：

```sh
env A90_AMC_LIBRARY=/path/to/DefaultLog/kernel3 \
  cargo test --locked --lib existing_library_files_compile -- --ignored
```
