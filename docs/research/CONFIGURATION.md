# 新建配置主向量

`bloody-a90-configuration.h` 可以从动作和参数构建新的按键配置主向量。
调用者不需要指定空闲地址，也不需要手工计算宏引用。
该模块只处理离线缓冲区。驱动没有调用它。

## 输入与分配

构建器接受以下输入：

- 1 至 7 个配置，以及选中的配置索引。
- 每个配置的 24 组按下、释放动作。
- 每个配置的向下、向上滚轮动作。
- 每个配置的 162 组手势动作。省略时生成完整的空动作表。
- 每个配置的两个原始元数据字。
- 16 个辅助动作，以及后面的六个原始参数字。
- 头部第 5、6 字的原始参数。

每个动作可以是 `bloody_a90_macro_event` 或完整的已编译宏。
宏的指针和长度必须同时提供。
宏检查器检查指令宽度、END 位置和跳转目标。
直接动作使用现有事件编码器。它不接受调用者提供的裸存储引用。
所有必需的动作都应明确初始化。结构体清零不会生成空动作。

构建器按以下顺序分配存储：

1. 16 字头部。
2. 宏池。
3. 22 字辅助块。
4. 每个配置的两个元数据字。
5. 按键动作表及其配置指针列表。
6. 滚轮动作表及其配置指针列表。
7. 手势动作表及其配置指针列表。

相同的编码后按键表和手势表共用存储。
滚轮表分别分配，与 EXE 的顺序一致。
宏池支持指令边界上的相同程序和后缀共用。
该优化不要求输出字节与 EXE 的分配结果完全相同。

构建器生成所有内部指针。
宏引用为 `c000 | 相对字地址`。
总长度不得超过 `3000` 十六进制字节。
头部为 `a4a4/ffff`，第 12 字为 `ffff`。
第 13 至 15 字为零。
两个校验值覆盖主向量第 4 字至末尾。

## 证据与限制

结构和分配顺序来自 EXE 函数 `00619b60`。
构造函数 `00617c8c` 建立 16 字头部和 22 个辅助记录。
函数 `006112e0` 区分直接动作和宏引用。
`00633d7c` 与 `00633de8` 分别参与按键表和手势表的比较。
分析对象的哈希见 [PROTOCOL.md](PROTOCOL.md)。

此构建器只生成内部主向量。
它尚未生成灯效表、外部存储向量或主机动作配置。
第 13 字关联的五组数据是灯效表。此前将其记为射击表的判断不正确。
读取的保存表若带有灯效列表，构建器原样保留其向量并重建列表；否则第 13 字为零。
函数 `0062c498` 的格式和证据见 [SHOOTING.md](SHOOTING.md)。
它也不将出厂表自动转换成输入对象。
输入中的元数据和六个参数保持原始字值。
它们的完整字段含义仍需检查。

头部标志只允许 EXE 此路径中出现的位 2、3、4、6、7。
允许一个标志位不表示本机支持该选项。
调用者仍需检查型号能力和原始参数的组合。
构建成功不表示设备执行通过，也不表示可以安全写入。

## 接口

```c
int bloody_a90_build_configuration(
    uint16_t model,
    unsigned int firmware,
    const struct bloody_a90_configuration *config,
    uint8_t *output,
    size_t capacity,
    size_t *written);
```

当前仅接受型号掩码 `04fc` 和固件 `07`。
成功时返回零，并将实际长度写入 `written`。
失败时输出缓冲区不变，`written` 为零。
计数器必须与输入、输出缓冲区分离。
函数支持宏输入缓冲区与输出重叠。

完整的调用示例见 `test-configuration.c`。
输出可以交给离线解析器和 [保存计划](SAVING.md)。

## 验证

```sh
cc -std=c11 -Wall -Wextra -Werror -UNDEBUG \
  -fsanitize=address,undefined -g \
  contrib/bloody-a90/test-configuration.c -o /tmp/a90-configuration-test
env ASAN_OPTIONS=detect_leaks=0 /tmp/a90-configuration-test
python contrib/bloody-a90/test_configuration.py
```

测试构建了 1 至 7 个配置，检查共享表和独立表的分配。
错误测试覆盖空间不足、缺少 END、错误型号、错误参数和输出不变。
重叠测试将输出缓冲区内的旧宏作为输入。

独立 Python 测试逐字比较 821 字的明确预期结果。
该示例包含两个配置、点击宏、按住重复宏和末尾手势动作。
位移宏的操作数字值为 `262f`，用来检查 END 与操作数的区别。
示例还包含 `shoot index 4` 和 `shoot index 7` 两个直接动作。
两个校验值为 `a1d0/a785`。

备份解析器检查新分配的按键、滚轮和宏引用。
离线保存计划将 1642 字节配置分成 52 块。
最后一块补零到 1664 字节。
逻辑重建结果与构建器输出一致。
这些测试不访问鼠标。
