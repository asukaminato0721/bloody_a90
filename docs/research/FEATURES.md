# 官方配置功能对照

目标是让 A90 在 Linux 上获得官方软件的配置效果。
下表记录 Rust 工具的状态。“实机”表示已在本机 A90（固件 07）上写入并检查效果。
写入流程、安全限制和测试记录见 [WRITES.md](WRITES.md)。

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 灯光亮度 | 实机 | 关闭和三档，命令 `11` 立即生效并读回。 |
| 五档 CPI、当前档位 | 实机 | 保存后用命令 `0d` 立即应用。运行值、传感器更新和持续移动检查通过。界面从鼠标读出并反查 DPI。 |
| 独立 X/Y CPI | 实现 | 与等轴共用同一写入路径，比例换算来自 EXE。 |
| 回报率 | 实机 | 保存后立即应用，保留当前 DPI 档位。实测 125、500、1000 Hz。重新插入时可能改用硬件设置，见 [RUNTIME-SENSITIVITY.md](RUNTIME-SENSITIVITY.md)。 |
| 按键映射 | 实机与编码检查 | 七个模式分别编辑。普通映射已有实机结果。顶键手势、组合键、办公预设、媒体及系统键、主机动作和滚轮映射已接入。新映射的实体效果仍待检查，见 [KEY-MENU.md](KEY-MENU.md) 和 [WHEEL.md](WHEEL.md)。 |
| 按键查询 | 实机 | 读取按键状态字节，确定 1 至 5、9、10、11 号物理按键。 |
| 普通宏 | 实机 | 存入宏池，按下和弹起程序分开。 |
| 宏重复、条件、变量 | 实机 | 三种重复方式、变量、条件、`gowhile`、`ifkey`。 |
| 宏中断 | 实机 | 松开、再按和指示灯报告 `07` 三种停止方式。 |
| 奥斯卡II 测试 | 实现 | 与官方相同，写入当前模式的后侧键。 |
| 鼠标位移和绝对移动 | 实现 | 编码和保存已实现。本机的授权数据禁止宏中的位移，见 WRITES.md。 |
| HighLanguage、AMC | 实现 | 全部 12 个官方 Sniper 文件可编译，AMC 可导入导出。 |
| 奥斯卡III 宏库 | 实现 | 分类、新建、保存、另存为、文件和分类重命名、删除及恢复上次删除。使用 AMC 文件。见 [LIBRARY.md](LIBRARY.md)。 |
| 多配置 | 实机 | 七个配置，配置循环键正常。 |
| 连击、射击 | 编译与保存 | 七个槽位支持 A/B/C/D 和奥斯卡宏，包含 D 类辅助参数。已确认本机核心 2 缺少左键射击入口，界面会显示此限制。官方核心 3、4 包含入口，尚未实机验证。见 [CORES.md](CORES.md)。 |
| 配置文件 | 实现 | 灵敏度块和按键主向量的导入、导出。 |
| 编辑状态保存 | 实现 | 关闭时保存 DPI 草稿、宏文本和路径。 |
| 抬起高度、校准 | 实机读回 | 1 至 16 级，五秒表面采样。16 级的保存、运行值与校准状态通过读回检查。未测量物理距离，见 [CALIBRATION.md](CALIBRATION.md)。 |
| 按键响应时间 | 实机读回 | 0 至 16 ms。保存按键表第 6 字，命令 `0c` 更新运行值。8 ms 的运行值读回通过。未测量物理延迟。 |
| 应用程序配置关联 | 实机 | 读取 KDE Wayland 或 X11 的前台应用。命令 `0c` 切换运行配置。规则切换、手动切换保持和恢复通过实机检查。规则保存在本机，见 [ASSOCIATIONS.md](ASSOCIATIONS.md)。 |
| 手势 | 全局路径、浮动提示、文字和窗口动作 | 两套文件编辑、释放识别和 16 合一即时响应。支持独立触发键、键盘、常用媒体键、鼠标、AMC 主机宏、应用缩放、打开目标、指针下窗口的最小化和最大化。KWin EIS 及 Wayland 虚拟键盘支持 Unicode 文字，原生 KWrite 和独立 Sway 的 Qt 编辑器检查通过。普通手势支持 Wayland / X11 浮动提示。方向边界与原程序的 2,362,368 行参考结果一致。隔离路径、窗口变化和实机启停检查通过。X11 等桌面的文字输入、其他动作类型和人工画图效果仍需检查。见 [GESTURE-RUNTIME.md](GESTURE-RUNTIME.md)。 |
| 截图工具 | Linux 工具调用 | 手势可启动用户选择的截图应用，支持独立参数。官方 `Simulator=16` 动作需手动替换为“打开文件或程序”。原编辑器不重做。 |
| 桌面画笔、语音工具 | Linux 工具调用 | 使用相同的程序和参数设置。官方 `Simulator=17/29` 动作需手动替换。工具内的绘图和录制状态由所调用的应用处理。见 [HOST-SPECIAL-ACTIONS.md](HOST-SPECIAL-ACTIONS.md)。 |
| RGB 灯效 | 不适用 | A90 为单色灯光。固件 07 的灯效列表读取函数没有已发现的调用者。 |
| 指针速度、双击速度、滚动行数 | KDE 实机 | KWin 属性、配置键值和独立 Qt 程序读值检查通过。测试结束后恢复原值。排除了错误的键盘接口。GNOME 未做本次检查，见 [KDE-SETTINGS.md](KDE-SETTINGS.md)。 |
| 4-Way Wheel | 部分实现 | KDE Wayland 的窗口区域转换、每应用分界、反向区域、每核心开关及方向图标，与手势共用读取器。独立完整输入路径、图标行为及实机启停检查通过。整页滚动、横向字符数和可拖动分隔图标仍待实现，见 [WHEEL4D.md](WHEEL4D.md)。 |

功能来源包括官方 EXE 的 VCL 元数据、`Data/Mouse/Forms`、
`Data/Mouse/ini/MouseConfig.ini` 和英文默认配置。
这些文件覆盖多个鼠标型号。某个窗口存在，不表示 A90 支持该窗口的全部选项。
